Mia

A friendly, local interface for Hermes Agent, with private agents and bots. Multiplayer rooms and shared bots are upcoming.

How it works

Hermes Agent is the runtime that connects to AI providers, manages provider sessions, tokens and refresh, and performs inference. Mia supplies the interface, room coordination, and bot orchestration.

  • Provider connections use ChatGPT, Grok, or API access configured through Hermes Agent.
  • Mia does not implement “Sign in with ChatGPT” or provider OAuth with a Mia client ID.
  • Mia does not persist ChatGPT or Grok credentials. Private agents and Solo bots use their owner’s provider subscription or API credential—consumer subscriptions are never pooled.

Privacy and upcoming multiplayer

Solo work stays private

Only the owner can request work from a private agent or Solo bot. It may use that owner’s Hermes session.

Shared bots will be API-only

When multiplayer ships, shared bots must use paid API credentials and never a member’s consumer ChatGPT or Grok subscription.

Rooms will coordinate people

Upcoming multiplayer services will coordinate rooms, presence, and shared-bot calls without exposing or invoking another person’s private agent.

Your local work stays local

Provider authentication and local agent files remain under Hermes Agent’s control on the user’s computer.

Compute is transparent

This build has no in-app platform billing. Provider charges remain with the connected provider account, and local diagnostics show the installation’s active and queued capacity.
